# Using the Doodlore references

Before artwork generation read ART_DIRECTION.md, GENERATION_PROMPT.md, persona/PERSONA.md, studio/STUDIO_GUIDE.md and signatures/README.md.

Attach only relevant references to the image tool: studio board for room/layout, hand board when hands appear, identity reference when Clara's face appears, signature sample for handwriting, and any separately verified portrait reference for the subject of a tribute. Clara's identity reference must not replace a real tribute subject's face.

Prompt roles explicitly. Preserve desk orientation and left window lighting. A drawing is marks on a physical sheet within a photographic-style image. Finished art carries Doodlore lettering with natural small handwritten variation, not an identical stamped logo.

For hands: right hand holds pen; birthmark belongs only on the dorsal LEFT hand near thumb base. Specify five digits per hand, short bare nails and no jewelry. Avoid covering or inventing birthmarks when the relevant skin is not visible.

Review: paper edges and perspective; objects in correct locations; light direction; face continuity if visible; correct hand count/anatomy and handedness; birthmark position; signature spelling; appropriate factual caption and disclosure. Reference boards reduce drift but do not guarantee it. Reject incorrect panels as guides.

All generated boards are AI-created reference assets, never records of a real artist. Keep them outside queue. Save actual generation prompts and preserve original outputs. No publishing or scheduler changes are required for this reference setup.

## Manual review location (current workflow)
All newly generated content packages belong in queue/not-approved/evergreen or queue/not-approved/timely. The user manually moves approved packages into queue/evergreen or queue/timely. This supersedes earlier draft-location guidance; see APPROVAL.md. Never auto-approve by moving into the normal queue.

## Caption disclosure preference (latest)
The user will manually apply the platform AI label. Do not include AI-created disclosure lines or AI hashtags in public caption.txt files. Write natural, thoughtful captions with five relevant hashtags, without claiming physical handmade authorship, real eyewitness experience, or a real artist's biography. Retain factual clarification that a scene is an artistic interpretation when needed. Internal metadata must retain ai_generated=true. This supersedes earlier requirements for AI disclosure inside captions.
