# Doodlore signature reference

`doodlore-signature-sample.png` is the isolated AI-generated signature reference. `../references/phone-photo-pencil-approved-direction.png` shows its placement and scale within a drawing photograph.

Use the signature as a handwriting anchor for future generations. Do not require pixel-identical copies: retain the D, letter sequence, general flow and underline, while allowing small handwritten differences. Always inspect the final spelling. Transparency is intended for the standalone reference; finished signatures should appear integrated into the physical medium and paper perspective.

The source artwork was the revised For Those Waiting test. The original image remains preserved. This sample establishes a studio mark for AI-created art.

Current size rule: use this image only for handwriting identity, not scale. On artwork the signature should occupy about 6-8% of paper width, with fine strokes and a short underline. Earlier examples show oversized signatures and are not size references.
